TeleRx Home Service Module - Fixed Version

Upload this complete HomeService folder into your website root:
  telerxbd/HomeService/

Main menu link:
  <a href="HomeService/home-service.php">Home Service</a>

Files:
  home-service.php      = main listing page
  service-details.php   = dynamic service details page
  data.php              = edit/add service content here
  _bootstrap.php        = safely includes ../header.php and ../footer.php from root
  assets/services/      = demo service images

Important:
- Do not move individual files outside the HomeService folder.
- Replace images inside assets/services/ if you want real photos.
- Keep the same image filenames if you do not want to edit data.php.
- This version does not force any font. It inherits the TeleRx website font from header.php/custom.css.
